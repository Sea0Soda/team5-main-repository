# useEffect 언제, 왜 쓰는가?

리액트에서 `useEffect`는 함수형 컴포넌트에서 **사이드 이펙트(부수 효과)** 를 처리하기 위해 사용하는 매우 중요한 훅입니다.  
예를 들어, 데이터 가져오기, 이벤트 등록, 타이머 설정 같은 작업을 할 때 사용됩니다.

---

## 1. useEffect 기본 구조

```jsx
useEffect(() => {
  // 실행할 코드
}, [의존성])
```

- 첫 번째 인자: 실행할 함수
- 두 번째 인자: 의존성 배열 (Dependency Array)

---

## 2. 동작 방식에 따른 세 가지 패턴

### 1) 마운트될 때 한 번만 실행

```jsx
useEffect(() => {
  console.log('처음 렌더링 시 1번 실행됨')
}, [])
```

- 빈 배열 `[]`을 넣으면 **컴포넌트가 처음 나타날 때만** 실행됨
- 예: 초기 데이터 로딩(API 호출)
- 쇼핑몰에 처음 들어가면 상품 리스트가 쫙 나오는 것 → 처음 한 번 API로 데이터 가져옴
- 로그인하고 나면 "환영합니다 OOO님" 같은 환영 메시지 띄우기

---

### 2) 특정 값이 바뀔 때마다 실행

```jsx
useEffect(() => {
  console.log('count가 바뀔 때마다 실행')
}, [count])
```

- `count`라는 상태값이 바뀔 때마다 실행됨
- 예: 상태 변경에 따른 UI 반응 처리
- 검색창에 글자 입력할 때마다 자동으로 검색 결과 리스트 바뀌는 것
- "좋아요 순", "최신순" 필터 바꿀 때마다 게시글 정렬 다시 되는 것
- 페이지네이션 숫자 눌렀을 때 → 해당 페이지의 데이터만 새로 보여주는 것

---

### 3) 언마운트(사라질 때) 정리 작업

```jsx
useEffect(() => {
  const id = setInterval(() => {
    console.log('타이머 작동 중')
  }, 1000)

  return () => {
    clearInterval(id) // 컴포넌트 사라질 때 타이머 제거
  }
}, [])
```

- `return` 안의 함수는 **컴포넌트가 사라질 때(clean up)** 실행됨
- 알람/타이머 기능 쓰다가 페이지 나가면 → 타이머 멈춤
- 채팅창 닫았을 때 "사용자 퇴장" 신호 서버에 보내기

---

## 3. 주의할 점

- 의존성 배열을 빼면 컴포넌트가 업데이트될 때마다 실행됨 (매 렌더마다!)
- 배열에 잘못된 값을 넣으면 무한 루프 발생 가능
- `useEffect` 내부에서 상태를 업데이트하면 **주의해서 사용해야 함**

---

## 4. 언제 쓰면 좋을까?

| 상황                    | 예시                       |
| ----------------------- | -------------------------- |
| 컴포넌트 처음 나타날 때 | API 요청, 초기 렌더링 작업 |
| 값이 바뀔 때 어떤 반응  | 필터, 검색어 입력 반응 등  |
| 사라질 때 정리 필요     | 타이머 제거, 이벤트 해제   |

---

## 마무리 요약

- `useEffect`는 리액트 함수형 컴포넌트에서 **부수 효과를 처리하는 도구**
- 의존성 배열을 활용해 **언제 실행할지 제어** 가능
- 정리(clean-up)를 할 수 있어 **메모리 누수 방지**에 도움
