# 자바스크립트 DOM 조작 방법 정리

## DOM이란?

DOM(Document Object Model)은 **HTML 문서를 자바스크립트가 다룰 수 있게 만든 객체 구조**입니다.  
웹 페이지의 요소들을 자바스크립트로 접근, 수정, 삭제할 수 있게 해주는 인터페이스입니다.

---

## 대표적인 DOM 요소 선택 메서드

| 메서드                   | 설명                                           | 예시                                      |
| ------------------------ | ---------------------------------------------- | ----------------------------------------- |
| `getElementById`         | ID 속성으로 요소 하나 선택                     | `document.getElementById('title')`        |
| `getElementsByClassName` | 클래스명으로 요소들 선택 (HTMLCollection 반환) | `document.getElementsByClassName('menu')` |
| `getElementsByTagName`   | 태그명으로 요소들 선택                         | `document.getElementsByTagName('li')`     |
| `querySelector`          | CSS 선택자로 요소 하나 선택                    | `document.querySelector('.card')`         |
| `querySelectorAll`       | CSS 선택자로 모든 요소 선택 (NodeList 반환)    | `document.querySelectorAll('.item')`      |

---

## 자주 사용하는 DOM 조작 메서드

| 동작             | 메서드                                            | 설명                             |
| ---------------- | ------------------------------------------------- | -------------------------------- |
| 텍스트 변경      | `textContent`                                     | 요소 내부의 텍스트를 읽거나 변경 |
| HTML 삽입        | `innerHTML`                                       | 요소 내부에 HTML 코드를 삽입     |
| 속성 제어        | `setAttribute`, `getAttribute`, `removeAttribute` | 요소의 속성을 설정/읽기/삭제     |
| 클래스 추가/제거 | `classList.add/remove/toggle`                     | 클래스 조작                      |
| 스타일 변경      | `element.style`                                   | 인라인 스타일 직접 설정          |

---

## 이벤트 리스너 추가하기

```js
const button = document.querySelector('#submit-btn')
button.addEventListener('click', () => {
  alert('버튼이 클릭되었습니다!')
})
```

---

## 실무에서의 팁

- `querySelector`와 `querySelectorAll`은 **CSS 선택자 문법**을 그대로 쓸 수 있어 가장 범용적
- `getElementsByClassName`과 `getElementsByTagName`은 실시간 HTMLCollection 반환 → 유사배열
- `NodeList`는 `forEach` 사용 가능하지만, `HTMLCollection`은 직접 반복문 돌려야 할 수도 있음
- 조작 대상이 많을 땐 **반복문(forEach)** + `querySelectorAll` 조합 많이 사용함

---

## 예제 코드

```html
<button id="btn">눌러봐!</button>
<p class="text">기존 텍스트</p>

<script>
  const btn = document.getElementById('btn')
  const text = document.querySelector('.text')

  btn.addEventListener('click', () => {
    text.textContent = '버튼이 눌렸습니다!'
    text.style.color = 'blue'
  })
</script>
```

---

## 마무리 요약

- DOM은 웹 문서를 JS에서 조작하기 위한 객체 구조
- 요소 선택 → 변경/삭제/스타일 조작 → 이벤트 연결까지 한 흐름으로 이해
- 다양한 선택 방법이 있지만 **querySelector 계열이 가장 범용적으로 사용됨**
