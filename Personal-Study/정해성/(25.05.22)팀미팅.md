# React 기초 개념 정리: 컴포넌트, 상태, Props, JSX

---

## 1. React란?

- React는 **UI를 구축하기 위한 자바스크립트 라이브러리**입니다.
- Facebook에서 개발했으며, **컴포넌트 기반**으로 사용자 인터페이스를 구성합니다.
- 주로 **단일 페이지 애플리케이션(SPA)** 개발에 사용됩니다.

---

## 2. 컴포넌트(Component)

- 컴포넌트는 **화면의 재사용 가능한 조각**입니다.
- 함수형 컴포넌트가 가장 많이 사용됨 (예전엔 클래스형도 사용)

```jsx
function Welcome() {
  return <h1>안녕하세요!</h1>
}
```

- 컴포넌트를 조합하여 복잡한 UI 구성 가능

---

## 3. JSX란?

- JSX는 **JavaScript + XML** 형태의 문법으로,  
  자바스크립트 코드 안에서 HTML을 작성하는 것처럼 보이게 합니다.

```jsx
const element = <h1>Hello, world!</h1>
```

- 실제로는 Babel이 아래처럼 변환함:

```js
React.createElement('h1', null, 'Hello, world!')
```

---

## 4. Props (속성)

- Props는 **부모 → 자식 컴포넌트로 데이터를 전달**하는 방법입니다.
- 읽기 전용이며, 자식 컴포넌트에서는 변경할 수 없습니다.

```jsx
function Greeting(props) {
  return <p>안녕하세요, {props.name}님!</p>
}

;<Greeting name="해성" />
```

---

## 5. State (상태)

- 컴포넌트 내부에서 **변할 수 있는 데이터**를 저장하는 공간
- useState 훅을 사용해 상태 정의

```jsx
import { useState } from 'react'

function Counter() {
  const [count, setCount] = useState(0)

  return (
    <div>
      <p>현재 카운트: {count}</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
    </div>
  )
}
```

---

## 6. 정리

| 개념     | 설명                                            |
| -------- | ----------------------------------------------- |
| 컴포넌트 | UI 구성 단위, 재사용 가능                       |
| JSX      | HTML과 유사한 문법을 JS 안에서 사용             |
| Props    | 부모가 자식에게 데이터 전달 (읽기 전용)         |
| State    | 컴포넌트 내부에서 변화하는 값 (setState로 변경) |
