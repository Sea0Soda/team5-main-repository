# 리액트 생명주기 & 웹 렌더링 방식(CSR, SSR, SSG)

---

## 1. 리액트 생명주기 (React Lifecycle)

리액트 컴포넌트는 **등장 → 업데이트 → 사라짐**의 과정을 겪으며, 이걸 "생명주기"라고 해요.

### 🔹 클래스형 컴포넌트 기준 주요 생명주기

| 단계                         | 메서드                             | 설명                                        |
| ---------------------------- | ---------------------------------- | ------------------------------------------- |
| 마운트(처음 생성될 때)       | `constructor`, `componentDidMount` | 컴포넌트가 처음 화면에 나타날 때            |
| 업데이트(상태/props 바뀔 때) | `componentDidUpdate`               | 렌더링 후 변경된 데이터 반영                |
| 언마운트(사라질 때)          | `componentWillUnmount`             | 컴포넌트가 DOM에서 제거될 때 정리 작업 수행 |

### 🔹 함수형 컴포넌트에서는?

`useEffect` 훅 하나로 생명주기 관리

```jsx
useEffect(() => {
  console.log('처음 또는 업데이트 될 때 실행')

  return () => {
    console.log('컴포넌트가 사라질 때 실행')
  }
}, [])
```

- `[]`: 처음 한 번 실행 (componentDidMount)
- `[변수]`: 해당 값이 바뀔 때마다 실행 (componentDidUpdate)
- `return () => {...}`: 언마운트 시 실행 (componentWillUnmount)

## 2. 웹 페이지 렌더링 방식: CSR, SSR, SSG

### 🔹 CSR (Client-Side Rendering)

| 특징      | 설명                                 |
| --------- | ------------------------------------ |
| 처리 주체 | 브라우저(클라이언트)에서 JS로 렌더링 |
| 초기 속도 | 느림 (JS 다운받고 실행돼야 보여짐)   |
| 장점      | 인터랙션 빠름, SPA 구현 쉬움         |
| 단점      | SEO 불리, JS 꺼진 환경에선 무용지물  |

**적합한 경우:** 내부 관리 페이지, 앱 형태 웹

---

### 🔹 SSR (Server-Side Rendering)

| 특징      | 설명                               |
| --------- | ---------------------------------- |
| 처리 주체 | 서버가 HTML을 완성해서 보냄        |
| 초기 속도 | 빠름 (HTML이 바로 옴)              |
| 장점      | SEO 유리, 첫 화면 빨리 뜸          |
| 단점      | 서버 부하 증가, 상호작용 JS가 느림 |

**적합한 경우:** 뉴스, 블로그, 초기 로딩 중요 서비스

---

### 🔹 SSG (Static Site Generation)

| 특징      | 설명                               |
| --------- | ---------------------------------- |
| 처리 주체 | 빌드 시 HTML 미리 생성 (정적 파일) |
| 초기 속도 | 가장 빠름                          |
| 장점      | 속도 + SEO 둘 다 좋음              |
| 단점      | 자주 변하는 데이터 반영 어려움     |

**적합한 경우:** 문서 사이트, 블로그, 랜딩 페이지

---

## 마무리 요약

| 방식 | 속도        | SEO | 적합한 경우              |
| ---- | ----------- | --- | ------------------------ |
| CSR  | 느림 → 빠름 | ❌  | SPA, 내부 도구           |
| SSR  | 빠름        | ✅  | 검색노출 중요한 서비스   |
| SSG  | 매우 빠름   | ✅  | 정적 콘텐츠, 랜딩 페이지 |
