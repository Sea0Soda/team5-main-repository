# React 개념 정리: Virtual DOM과 key의 필요성

---

## 1. 리액트에서 Virtual DOM이 무엇인지, 이를 사용하는 이유는 무엇인가요?

### Virtual DOM이란?

- Virtual DOM(가상 DOM)은 **브라우저의 실제 DOM을 추상화한 가벼운 자바스크립트 객체**입니다.
- 상태(state)나 props가 바뀌면, 전체 UI를 Virtual DOM에 다시 렌더링하고,
  이전 Virtual DOM과 비교(Diffing)하여 변경된 부분만 실제 DOM에 반영합니다.

### 사용하는 이유

| 이유            | 설명                                                                      |
| --------------- | ------------------------------------------------------------------------- |
| 성능 향상       | 실제 DOM 조작은 느림 → 변화된 부분만 최소한으로 갱신하여 렌더링 속도 향상 |
| 효율적인 렌더링 | 전체 UI를 다시 그리는 것처럼 작성해도, 실제로는 필요한 부분만 업데이트    |
| 선언적 UI 구현  | 개발자는 상태에 따른 UI만 정의하고, 최적화는 React가 자동 수행            |

### 한 줄 요약

> Virtual DOM은 **변경된 부분만 효율적으로 렌더링**하여 성능을 높이기 위한 리액트의 핵심 기술입니다.

## 2. 리액트에서 배열을 렌더링할 때 key를 써야 하는 이유는 무엇인가요?

### 이유

- React는 `key`를 기준으로 리스트 항목을 식별하고, **변경 여부를 판단**합니다.
- `key`가 없거나 불안정하면, 컴포넌트의 상태가 꼬이거나 **불필요한 리렌더링**이 발생할 수 있습니다.

### 좋은 key의 조건

- 고유한 식별자 (예: `id`)
- 절대 중복되지 않아야 하며, 가능하면 배열의 인덱스는 사용하지 않는 것이 좋음

```jsx
// 올바른 예시
items.map((item) => <li key={item.id}>{item.name}</li>)
```

### 한 줄 요약

> `key`는 **리스트 항목의 변경을 정확하게 추적**하고, **효율적인 리렌더링**을 가능하게 합니다.
